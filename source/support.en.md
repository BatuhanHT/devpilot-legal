# DevPilot Support

Answers to common questions. If you can't find yours, contact us using the details at the bottom of this page.

## How do I delete my account?

Open Profile → Settings → Privacy & Data, expand Delete Account, tap Delete Account and confirm. This permanently removes your account, conversations, messages, code library, projects and profile from our servers. It cannot be undone.

## How do I turn AI data sharing off?

Open Profile → Settings → Privacy & Data and switch off "Send data to AI". Chat and code analysis stop working while it is off. You can turn it on again at any time.

## What data is sent to the AI service?

Only when you use an AI feature: your message, your recent conversation history and any code or repository file content you attach. See the Privacy Policy for details.

## I see a message that I sent too many requests.

AI requests are limited per user to protect the service: 15 per minute and 200 per hour. Wait for the time shown in the message and try again.

## How do I open files from a GitHub repository?

Link a repository to a project in the Repositories tab. Public repositories work without a token. For private repositories, add a read-only access token in the GitHub section of the Profile tab; it is stored only in your device's Keychain.

## How do I change the app language?

Open Settings and choose a language. DevPilot supports English, Turkish, Spanish, Simplified Chinese and Hindi.

## Is my code stored?

Your chats, saved code snippets and projects are stored in your account so you can see them on your devices. Files you open or edit in the editor are not stored in your account; they are sent to the AI service only if you run an AI review.
